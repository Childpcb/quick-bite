# Quick Bite - Food Ordering System

## 📌 Project Description
Quick Bite is a web-based food ordering system built with PHP and MySQL. It allows customers to browse the menu, add items to their cart, and place orders. It also includes an admin panel for managing food items, orders, and users.

## ✨ Features
*   **User Side:**
    *   Browse food menu by category.
    *   Add items to cart and update quantities.
    *   Secure checkout process.
    *   Track order status.
    *   Contact form.
*   **Admin Side:**
    *   Admin dashboard with order statistics.
    *   Manage food items (Add, Edit, Delete).
    *   Manage orders and update delivery status.
    *   View registered users.

## 🛠️ Technologies Used
*   **Frontend:** HTML, CSS, JavaScript, Bootstrap
*   **Backend:** PHP
*   **Database:** MySQL
*   **Server:** XAMPP / Apache
